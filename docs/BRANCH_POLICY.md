# Branch Policy

- `main`: latest real-machine PASS / SEALED source authority.
- `develop`: next candidate; may contain STATIC PASS or unverified work.
- `phase/<name>`: isolated multi-step phase work.
- `fix/<name>`: targeted defect closure.
- `feature/<name>`: isolated feature work.

Promotion to `main` requires RPG Maker VX real-machine PASS and evidence logged in Linear/Drive. Never merge based only on static validation.
